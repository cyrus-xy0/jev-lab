# Jev Lab · 决策对比实验室

帮助团队直观理解 LLM 与 Jev 的交互差异，在同一页面准备输入、独立运行并比较结果的中文 Web 原型。

当前版本使用本地 Mock，不调用真实模型。耗时来自本地模拟流程，Token 按字符估算，不代表真实模型性能或费用。实验记录保存在当前浏览器，匿名展示也仅在本地生效。

## 快速运行

无需安装 npm 依赖或构建。安装 Python 3 后，在项目根目录运行：

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

浏览器打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。也可以将 `dist/` 部署到任意静态网站托管服务。

## 功能

- **认识 Jev**：用途、与 LLM 的区别、使用方法、适合与不适合的任务。
- **模型对比**：LLM 输入提示词；Jev 输入 state、question 与判断标准。两侧可独立启动、停止与重跑。
- **38 套场景模板**：包含 42 个请求阶段与 115 道判断题，支持 Choice、Noul、Score。
- **按需显示结果**：选择模板只填入输入；点击“运行 Jev”后才展示结果卡片。修改输入或切换模板会隐藏不再匹配的旧结果。
- **测试广场**：浏览官方场景和本地实验记录，支持复用任务与本地匿名预览。
- **结果详情**：查看请求与响应 JSON、返回的概率/分布、耗时和估算 Token。

## 接入真实模型

替换 `dist/mock-client.js` 的适配器，并遵循接口接入说明中的独立输入、事件与取消约定。真实模型密钥应配置在服务端环境中，由浏览器调用应用后端。
