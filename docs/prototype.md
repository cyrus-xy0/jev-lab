# Jev Lab 可点击原型

入口：https://jev-lab-side-by-side.xy-chen.chatgpt.site/?v=33#basics

- 「认识 Jev」为默认首页。用途、与 LLM 的区别、用法、适合任务和不适合任务五个模块单列排列，结构一致：标题、一句话简介；点击展开必要解释，再点收起；用法、适合任务和不适合任务分别配具体例子；悬停或聚焦不会自动展开。支持手机与键盘操作。
- 「模型对比」为同一场景提供两种不同起点。LLM 只有提示词输入框，可选豆包或 GPT，直接点击「运行 LLM」。Jev 在同一页面填写 state（当前状态）和 question；question 分为「问题描述」和「判断标准（criteria）」；Choice/Score 沿用逐项编辑，Noul 默认展示“是／否”两侧标准，可只填一侧或不填。直接点击「运行 Jev」；没有步骤导航和额外确认。
- 工具栏依次为模板库、游戏社区与玩家支持／内容审核与社区安全／电商商品处理／保险理赔材料初筛四个精选场景，以及重置。重置清空当前草稿和结果并停止当前调用，保留历史记录与 LLM 模型选择。默认输入为空。模版只准备两侧各自的输入；Jev 结果区仅显示待运行提示，点击「运行 Jev」后才展示结果卡片。两侧可先后或同时运行；无需等 Jev 填完才能运行 LLM，LLM 运行期间仍能填写 Jev。
- 每侧仅显示请求和结果两个模块。详情使用点击内嵌展开；主视图使用自然语言，请求和结果的详情各展示一份完整 JSON，不再重复拆解字段；旧记录未保存完整返回时会明确提示缺失。原先的处理过程来自本地 Mock 固定步骤，不再作为页面模块展示；运行中、失败、停止和重置状态仍保留。
- Jev 结果按题展示问题说明、类型和结论，点击卡片内嵌展开完整标准。Choice 突出返回选项；Noul 显示是/否两侧概率；Score 保留连续分数和等级位置。仅展示返回中实际提供的分布及置信度，当前 Mock 缺失的值不补造。未运行仅显示待运行提示，点击「运行 Jev」后展示结果卡片，完整返回后才出现答案；长结论可展开查看全文。
- 两侧分别保存请求、状态、耗时和 Token。编辑一侧会隐藏该侧旧结果，另一侧不变。独立停止或重跑一侧；只有两侧都完成且与当前输入匹配，才可匿名展示完整对比。
- 「测试广场」区分官方场景、我的场景、其他场景。38 套官方模版全部可用；我的场景包含全部个人实验，包括从官方模版发起的记录。尚未连接共享接口，他人列表显示空状态。
- 个人实验统一保留在「测试广场 · 我的场景」，取消单独的「我的实验」顶层入口；旧 #history 链接自动跳转到我的场景。历史回看保留两侧原始输入；使用历史或广场任务会创建待运行草稿，清空运行引用。刷新会将未完成的调用标为停止。
- 匿名预览分别检查 LLM 提示词、Jev state、全部 questions 和判断标准。任一公开输入修改后，原始过程、结果及指标全部隐藏，避免旧内容残留。仅在当前浏览器展示。

## 模版库

38 套模版按业务目标分为六类：客服与客户经营 4、内容审核与安全 6、知识检索与文档 8、数据整理与分类 9、业务审核与评估 7、工具选择与控制 4。原资料的 42 个请求、115 道判断题完整保留，模版库与测试广场使用相同分类。

详情先说明业务场景，再展示实际 LLM 提示词与使用入口；多个请求时可切换阶段。LLM 的 38 套自然语言配方依据实际材料生成，支持解释、建议与必要澄清，不复制 Jev 问题字典。两侧仍使用等价的事实、规则和业务目标。本轮按场景、事实、约束和任务目标复核全部 42 个请求阶段，修正 15 个场景的 16 个阶段，避免把提取变成建议、判断变成额外执行或缩小原任务范围；不要求两侧文字或输出形式相同。场景 brief 不进入提示词；预览与实际发送文本一致。Jev state、question 和完整 JSON 在分屏中查看。

Jev 表单保留对象或字符串 state、多道 questions、题目 ID、Choice 的候选键、Noul 的可选是／否判断标准，以及 Score 的等级顺序。Choice 候选答案、Score 评分标准均逐项编辑，可添加、修改和删除；Choice 删除时保留其他选项的原标识，Score 按 0 起始的有序等级展示。Noul 标准支持字符串以及结构化内容；可逐字段编辑嵌套标准，也可明确改用文字标准。未编辑时保持原有省略、null、单侧标准及扩展字段，空占位不发送。类型切换保留各自内容，多行文本及原请求中的扩展字段原样保留。匿名预览使用独立的同类编辑器与完整请求预览，取消不会改变源记录。同页可切换本次请求中的各题，来回切换不会丢失填写内容。表单原样时，发送原始 body；修改时仅更新明确编辑的字段，不把 LLM 提示词自动当成 Jev state。

C06、C08、C16 的第二份请求使用资料提供的假设中间状态；C12 为独立的输入和输出检查。请求模版切换不会被当作前一步运行已完成。

## 公共控件

模型、请求、问题和答案类型的下拉选择统一使用本地固定版本 Tom Select 2.6.2，支持键盘操作、焦点恢复和运行时禁用。弹窗关闭按钮统一使用线性图标和 44px 点击区域；手机端菜单保持在屏幕范围内。

## 当前运行范围

仍使用本地 Mock，未连接真实模型或业务系统。官方原样请求使用明确标为模拟的值；未覆盖的自定义材料或判断标准会显示等待模型接入，不沿用旧答案。四个快速场景可按已覆盖的本地条件选择模拟分支。

豆包与 GPT 共用模拟逻辑。耗时为本地异步流程测量值，Token 按字符估算，不能用于模型性能或成本判断。所有数据仅保存在当前浏览器。
